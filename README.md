# MOL asortiman

Radni dokument za izmenu asortimana MOL pumpe: Fresh Corner (kafa, viršle, hrana), raspored frižidera i piva, impulsna kupovina, Discover zona i kalkulator pokrivanja troška pumpe.

Cela stranica je u `index.html` (statičan HTML, bez build koraka). Nije zvaničan materijal kompanije MOL.
