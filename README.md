# MOL asortiman

Radni dokument za izmenu asortimana MOL pumpe: tlocrt radnje sa slikama i predlozima po zoni (frižideri, gondola sa pivom, kafa i hrana, kasa, ulaz, alkohol i čips).

Cela stranica je u `index.html` (statičan HTML, bez build koraka), slike su u `img/`. Nije zvaničan materijal kompanije MOL.
